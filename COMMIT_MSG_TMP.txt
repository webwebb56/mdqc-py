v0.3.0: dashboard QoL + configurable report columns

From the Evosep pilot feedback. Six items:

1. Dashboard: control-type dropdown no longer collapses when the recent
   data happens to be a single type. Always offers the canonical QC
   types (SSC0, QC_A, QC_B, BLANK) plus anything else seen in the data,
   so operators can filter back to historical data instead of being
   stuck in whatever the latest batch contains.

2. Dashboard: KPI tiles now distinguish "Peptides" (the science-meaningful
   per-peptide recovery rollup, computed from peak_area > 0) from
   "Transitions" (the raw precursor/transition row count from Skyline).
   Tile labels and tooltips updated. Previously "Targets 407/407" was
   confusing — 407 was the transition count, not peptide count.

3. Configurable column mapping. New [skyline.report_columns] section in
   config.toml lets operators declare which CSV columns map to which
   canonical metrics. Each entry can be a single column name or a list
   of column names (auto-summed — for split MS1+fragment intensity).
   Falls back to the built-in alias dictionary for any canonical not
   overridden, so default deployments need no config change. Unblocks
   custom .skyr exports.

4. SPD classifier + filter. Filenames like "200spd" / "500SPD" / "100_SPD"
   are now parsed into a numeric SPD field, surfaced in the payload
   schema, and offered as an orthogonal dashboard filter alongside
   instrument and control_type.

5. Y-axis toggle on the Levey-Jennings grid: z-score (current behavior),
   raw value, or log10. Westgard ±σ guide lines and per-peptide z-score
   baseline-mode dropdown only apply in z-score mode; raw/log modes
   plot the metric value directly. Helps when chasing intensity drift
   that the z-score view normalizes away.

6. Run exclusion (without deletion). Sidebar UI lets the operator mark
   first-of-series outliers (column not fully equilibrated, etc.) as
   excluded from baseline computation and chart rendering. Persists to
   <folder>/exclusions.json so it survives restarts. Underlying payload
   files are untouched.

Tests: 5 new column-override tests, 5 new SPD-classifier tests; all
360 unit tests pass.
